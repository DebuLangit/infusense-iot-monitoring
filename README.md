# InfuSense — Sistem Monitoring dan Kendali Cairan Infus Berbasis IoT

**InfuSense** adalah sistem pemantauan dan kendali cairan infus berbasis *Internet of Things* (IoT) yang mengukur sisa volume cairan dan laju tetesan secara *real-time* menggunakan sensor optik dan *load cell* berbasis ESP32. Sistem ini dirancang untuk mempermudah tenaga medis dalam mengawasi kondisi infus pasien serta memberikan peringatan otomatis jika terjadi kondisi abnormal.
